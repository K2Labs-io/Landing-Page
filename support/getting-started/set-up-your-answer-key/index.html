Set up your answer key

Getting Started · 3 min

You can enter your answer key by tapping each answer manually, or by scanning a pre-filled bubble sheet. Both methods produce the same result.

Step 1: Open or create a test

Tap an existing test from the home screen, or create a new one. The answer key is attached to the test and can be edited at any time.

Screenshot: Home screen showing the test list with several tests. One test is tapped, opening the test detail screen.

Step 2: Tap "Answer Key"

From the test detail screen, tap the Answer Key button to open the key editor.

Screenshot: Test detail screen with an "Answer Key" button or section prominently visible.

Step 3: Tap each question and select the correct answer

Each row is a question number. Tap a row and select A, B, C, or D. The selected answer is highlighted and the next question is focused automatically.

Screenshot: Answer key editor showing a numbered list of questions. Question 3 is selected with "C" highlighted in the brand color. Questions 1 and 2 already show their answers; questions 4 onward are empty.

Step 4: Review the completed key

Once all questions have an answer, review the key before saving. Tap any question to change its answer.

Screenshot: Completed answer key with all questions filled in. Each row shows a question number and its answer letter. A "Save" or "Done" button is visible at the top or bottom.

Step 5: Save the key

Tap Save. The test is now ready to scan. You can always return to edit the key later — any changes will automatically regrade all scanned sheets.

Screenshot: Test detail screen after saving, showing the answer key as complete with a checkmark or "Key set" indicator, and the Scan button now active.
