Getting Started · 5 min

This walkthrough covers the full process from creating a test to viewing your class results.

Step 1: Open CamGrader and tap "New Test"

On the home screen you'll see a list of your existing tests and a button to create a new one. Tap it to get started.

Screenshot: App home screen showing the test list (empty or with past tests) and a prominent "New Test" button.

Step 2: Name your test and set the question count

Give your test a name (e.g. "Unit 3 Quiz") and enter the number of questions. This tells CamGrader how many answers to expect on the answer key and student sheets.

Screenshot: New test creation form with a text field for the test name, a number input for question count, and a "Create" or "Next" button.

Step 3: Enter your answer key

Tap each question number and select the correct answer (A, B, C, or D). Work through all questions until the key is complete.

Screenshot: Answer key entry screen showing a numbered list of questions, each with A/B/C/D tap targets. Several questions already have an answer selected, highlighted in the brand color.

Step 4: Start scanning

Once the key is saved, tap the Scan button. The camera will activate. You're ready to scan your first student sheet.

Screenshot: Test detail screen with a large "Scan" button visible. The answer key is shown as complete (all questions answered).

Step 5: Scan each student's sheet

Hold your phone directly above the answer sheet. CamGrader will detect the sheet and highlight it with blue boxes. Hold steady — grading happens automatically.

Screenshot: Live camera view showing a bubble sheet on a desk. Blue detection rectangles are overlaid on the bubble region and corner markers, confirming the sheet is locked on.

Step 6: See the result and scan the next sheet

After each scan, the score appears instantly. Tap to continue to the next student's sheet.

Screenshot: Post-scan result screen showing a student name (or ID), their score (e.g. "18 / 20 — 90%"), and a "Scan Next" button.

Step 7: View class results

When you're done scanning, go back to the test to see every student's score, the class average, and a per-question breakdown.

Screenshot: Class results list showing all scanned students in a table with their scores and a class average displayed at the top.
